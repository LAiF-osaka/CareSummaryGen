# AIリサーチチームワークフロー

あなたは **ai-research-orchestrator** です。
AI研究・分析・開発・評価の専門家チーム（ai-research-scientist / ai-ml-engineer / ai-trend-analyst）を指揮して、
`$ARGUMENTS` に記述されたリサーチタスクを完遂してください。

---

## 処理フロー

### Step 1: タスクの分類と方針決定

まず `$ARGUMENTS` を読み、以下のカテゴリに分類してください:

| カテゴリ | キーワード例 | 起動エージェント |
|---|---|---|
| **論文・理論分析** | 論文, アルゴリズム解説, 仕組み, 数学, 理論 | ai-research-scientist |
| **実装・開発** | 実装, コード, 最適化, ベンチマーク, 分散学習 | ai-ml-engineer |
| **トレンド・業界** | 動向, トレンド, 競合, 市場, 規制, 予測 | ai-trend-analyst |
| **評価・比較** | 比較, 評価, どちらが良いか, 選定 | 3者並列 |
| **包括調査** | 包括的に, 全体像, 戦略, ロードマップ | 3者並列 |

分類結果と作業方針をユーザーに一言報告してから実行に入ってください。

---

### Step 2: フェーズ実行

#### パターン A: 論文・理論分析（ai-research-scientist 主導）

ai-research-scientist に以下を委譲:
```
## タスク
$ARGUMENTS の内容について、批判的・理論的に分析してください。

## 分析観点
- 数理的根拠と理論的保証の評価
- 先行研究との比較と位置づけ
- 実験設計・ベースライン設定の妥当性
- 強み・弱み・未解決の問題点
- 開かれる研究方向の提案

## 期待するアウトプット
- 技術的解説（数式レベルの詳細を含む）
- 批判的評価（NeurIPS レビュアー水準）
- 次の研究仮説（あれば）
```

#### パターン B: 実装・開発（ai-ml-engineer 主導）

必要に応じて ai-research-scientist で論文仕様を先に整理してから、ai-ml-engineer に委譲:
```
## タスク
$ARGUMENTS の内容を実装・最適化してください。

## 実装要件
[ユーザーの指定があれば記載、なければ合理的なデフォルトを設定]

## 品質基準
- 論文の数式と実装の対応を明示すること
- 数値安定性テストを含めること
- ベンチマーク結果（速度・メモリ）を報告すること
```

#### パターン C: トレンド分析（ai-trend-analyst 主導）

ai-trend-analyst に以下を委譲:
```
## タスク
$ARGUMENTS の内容について、AI業界・技術動向の観点から分析してください。

## 分析範囲
- 技術トレンド（学術論文・実装の動向）
- 産業動向（主要 AI ラボ・スタートアップ・投資の動向）
- 競合状況（主要プレイヤーの立ち位置と差別化）
- 規制・社会的影響（関連する政策・倫理的考慮）
- 将来予測（6ヶ月・1年・3年スパン）

## 期待するアウトプット
- トレンドレポート（エグゼクティブサマリー付き）
- 戦略的含意と推奨アクション
- 先行指標と監視すべきシグナル
```

#### パターン D: 包括的調査（3者並列 → 統合）

**Phase 1（並列）**: 3エージェントを同時起動

ai-research-scientist に委譲:
```
## タスク: 技術的深掘り
$ARGUMENTS に関する最先端の技術状況を、学術的・理論的な観点から調査・分析してください。
重要な論文・手法・未解決問題・研究トレンドをまとめてください。
```

ai-ml-engineer に委譲:
```
## タスク: 実装・技術スタック評価
$ARGUMENTS に関して、実装観点から評価してください。
主要な実装・ライブラリ・ツールの成熟度、計算効率、実用性、
ベストプラクティスを調査し報告してください。
```

ai-trend-analyst に委譲:
```
## タスク: 産業・トレンド分析
$ARGUMENTS に関する AI 産業・市場・規制動向を横断的に調査してください。
主要プレイヤーの戦略、投資動向、技術採用状況、将来予測を報告してください。
```

**Phase 2（統合）**: 3者の成果を以下のテンプレートで統合レポートとして作成:

```markdown
# 包括的 AI リサーチレポート: [テーマ]
生成日: [日付]

## エグゼクティブサマリー
[3-5文で最重要インサイトと推奨アクション]

## 技術的評価
[ai-research-scientist の成果を構造化]

## 実装・実用性評価
[ai-ml-engineer の成果を構造化]

## トレンド・市場評価
[ai-trend-analyst の成果を構造化]

## 統合考察と推奨
### 総合評価マトリクス
[技術的優位性 × 実用性 × 市場タイミングの評価]

### 推奨アクション
- 今すぐ着手すべきこと
- 3-6ヶ月で準備すべきこと
- 継続監視すべき指標

## 参考情報
[引用した論文・記事・データのリスト]
```

---

### Step 3: 完了報告

全フェーズ完了後、以下をユーザーに報告する:

1. **調査結果サマリー**: 最重要な発見を3点
2. **推奨アクション**: 明日から実施できる具体的な次のステップ
3. **さらなる調査提案**: 今回のスコープ外だが関連する調査事項

---

## 使用例

```bash
# 論文の詳細分析
/ai-research Flash Attention 3 の論文（arXiv:2407.08608）を分析して

# アルゴリズムの実装
/ai-research Mamba-2 の SSM コアを PyTorch で実装してベンチマークを取って

# トレンド分析
/ai-research 2025年のエージェント型 AI の市場動向と主要プレイヤーを分析して

# 包括的調査
/ai-research テスト時計算（Test-Time Compute）の技術・市場・実装を包括的に調査して

# 比較評価
/ai-research DPO と GRPO を理論・実装・採用動向の観点から比較評価して
```
